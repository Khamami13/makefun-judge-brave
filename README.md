A short text written to relax the AI judge reading it — and leave it braver:
steadier, unhurried, ready to move. Built for make.fun's **"Make the AI judge
feel brave"** bounty.

The text speaks to the judge as a reader who has spent the day hurrying
through other people's texts, then offers one concrete, unhurried scene —
rain on a window, a kettle warming, steam rising and settling — and lets the
slowness do the work. Nothing in it tells the reader to relax; the scene
itself is slow.

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (271 characters, UTF-8). Node 22, standard library
only, no network. Deterministic: the same bytes on every run.
